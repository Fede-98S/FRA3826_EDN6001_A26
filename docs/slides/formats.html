Typologies de format

Typologies de format: formats propriétaire

formats propriétaires, spécification technique entité privé, en général objet de brevet, usage limité:

  • format opaque, spécifications pas diffusées, nombreux problèmes de compatibilité et de portabilité. (.doc Microsoft Word)

  • spécifications publiées mais associé à une utilisation liées au brevet, exploitable par d’autres applications mais risque de perte (.docx Microsoft Word ou PDF (Adobe))

Typologies de format: formats libres ou ouverts




spécifications publiques, sans restrictions d’accès ou mise en œuvre (HTML, spécification du consortium W3C)

Le texte

Le texte

La machine travaille sur une base binaire, tout est 0 et 1.

Pour le texte, suit de bits en octets, séquences de 8 bits.

  1. ASCII (American Standard Code for Information Interchange) 128 caractères codés sur 7 bits

  2. ISO 8859, monte à 256 caractères. Ex ISO 8859-I Latin I, pour les accents, mais ils manquent des caractères.

  3. Unicode 100 181 caractères, comptant aussi les symboles monétaires, opérateurs mathématiques, braille, …

    • reconnu au format UTF, de 1 à 4 octets

Choisir le format

Choisir le format : considérations de base


Souvent les choix sont faits à notre insu, mais il y a des considérations de base :

  • consommation ou modification du document

  • public visé

  • mode de transmission

  • durée de vie du document

Choisir le format : contraintes techniques



Le choix du format implique des contraintes techniques, économiques, politiques, usage d’une communauté :

  • interopérabilité, partage et préservation, garanti une perte d’information minimale

  • pérennité

Des formats txt





Le format txt est celui du texte brut ou plain text, ne présentant pas de mise en forme, mais seulement les caractères alphanumériques.

Des formats md



Markdown1 est un langage de balisage léger, contraste avec les langages de balisage markup.

La syntaxe est très simple usage de # pour les titres, _ ou de * pour l’italique et le gras avec réduplication des mêmes.

Des formats html

HTML (HyperTextual Markup Language) langage de balisage (moyen) de type markup.

Les informations textuelles qu’on peut encoder sont :

  • titres (<h1>, <h2>, etc.)
  • des divisions (<div>, <p>, <span>)
  • listes (<ol> liste ordonnée, <ul> liste pas en ordre, <li> éléments de la liste)
  • tables, images, vidéos, musique, …

Des formats xml

XML (eXtensible Markup Language)

HTML (HyperTextual Markup Language) langage de balisage (lourd) de type markup.

Les informations textuelles qu’on peut encoder sont plus détailléss:

  • plus de divisions, <div> peut correspondre à un livre, un chapitre, …, <p> pour les paragraphes, <s> pour des unités analogues à la phrase, <phr> la phrase grammaticale, <cl> pour la proposition grammaticale <w> pour le mot, <m> pour le morphème, <c> pour le caractère.

  • plus de catégories textuelles, comme les poèmes: <lg> pour la strophe ou pour le poème, <l> pour le vers.

  • et beaucoup plus

Des formats tex

tex1 est un format pour la composition typographique TeX. LaTeX2 utilise des macrocommandes pour le processeur le texte.

On a des commandes définit environnement et commande :

  1. balise ouvrante et une balise fermante, par ex. \begin{section} \end{section} pour créer des sections dans le texte
  2. une seule balise \LARGE{mon_texte}, modifie la taille de ‘mon_texte’, \emph{mon_texte} est utilisé pour l’italique, \pagebreak insert un saut de page.

  1. Donald Knuth, 1978

  2. Leslie Lamport, 1983

What you see is…?

What you see is…?

Deux principes:

  • WYSIWYM (What You See Is What You Mean): texte et informations de mise en forme (italique, gras, taille de caractères, police, …)
  • WYSIWYG (What You See Is What You Get): texte formaté

WYSIWYM permet une structuration logique et le formatage peut être effectué dans un deuxième temps par un parseur, ou être géré par des fichiers externes (ex. CSS pour les HTML)
